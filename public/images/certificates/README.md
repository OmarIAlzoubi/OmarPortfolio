# Certificate images

Add genuine certificate images here (PNG, JPG, WebP). Then set the corresponding entry in `data/assets.ts` to, for example, `"/images/certificates/aws-solutions-architect.png"`.

Keys: aws-solutions-architect, microsoft-generative-ai, microsoft-devops, ibm-generative-ai, ibm-rag-agentic, microsoft-power-bi.

The gallery has an accessible in-page preview and an honest fallback for missing or failed images. Power BI remains marked In progress. Adding an image does not change credential status.
